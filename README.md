# CoreCalc

A modern, stylish calculator application with a web3-inspired design aesthetic. This calculator provides standard arithmetic operations with a sleek, glass-morphic UI.

![CoreCalc](/public/output.png)

## Live Demo

Check out the live version of the calculator: [CoreCalc](https://corecalc.vercel.app/)

## Features

- **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division
- **Percentage Calculation**: Quickly calculate percentages
- **Sign Toggle**: Easily switch between positive and negative numbers
- **Decimal Support**: Perform calculations with decimal numbers
- **Operation History**: View your calculation history at the top of the calculator
- **Error Handling**: Prevents division by zero with helpful error messages
- **Responsive Design**: Works seamlessly on both desktop and mobile devices
- **Web3-Inspired UI**: Modern glass-morphic design with a dark theme

## How to Use

### Basic Operations

1. **Enter Numbers**: Click on the number buttons (0-9) to input values
2. **Perform Operations**:
   - Addition: Click the `+` button
   - Subtraction: Click the `-` button
   - Multiplication: Click the `×` button
   - Division: Click the `÷` button
3. **Calculate Result**: Press the `=` button to see the result
4. **Clear**: Press the `C` button to clear the calculator and start over

### Special Functions

- **Decimal Point**: Click the `.` button to add a decimal point
- **Percentage**: Click the `%` button to convert the current number to a percentage (divides by 100)
- **Sign Toggle**: Click the `+/-` button to change the sign of the current number

### Example Calculations

1. **Basic Addition**:
   - Press `5`, then `+`, then `3`, then `=`
   - Result: `8`

2. **Percentage Calculation**:
   - Press `50`, then `%`
   - Result: `0.5` (50% = 0.5)

3. **Chained Operations**:
   - Press `10`, then `×`, then `5`, then `+`, then `2`, then `=`
   - Result: `52` (10 × 5 = 50, then 50 + 2 = 52)

## Installation and Setup

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation Steps

1. Clone the repository:
   ```sh
   git clone https://github.com/zoha251284ansari/CoreCalc.git
   ```

2. Navigate to the project directory:
   ```sh
   cd CoreCalc
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```

5. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```
